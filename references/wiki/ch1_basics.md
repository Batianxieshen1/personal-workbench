# Ch1 什么是大模型

## 1.1 三个词：AI / 大模型 / Agent
- **AI（人工智能）**：一个大范围。只要机器能表现出智能行为（识别图片、听懂语音、翻译句子、下棋、推荐内容）都属于 AI。
- **大模型**：AI 里很重要的一类模型。通过大量数据训练，学到语言、图像、代码和知识中的规律。特点是**通用**：同一个模型可以写作文、做总结、翻译、看图、写代码。
- **Agent**：不是另一个大模型，而是**使用大模型的方式**。大模型负责理解和生成；Agent 在它旁边接上**工具、记忆和执行流程**，让 AI 不只是回答问题，还能一步步完成任务。

### 类比
- 大模型 = **大脑**：负责思考和表达。
- 工具 = **手和工具箱**：查资料、读文件、算数据、画图。
- Agent = **数字助理**：把大脑、工具和流程组织起来，把任务做完。

> 核心：Agent 的核心仍然是那个大模型。不同的是，它不只生成一段回答，还会调用工具、跟踪步骤，把任务继续推进（如前言里会安装 Python 的 Agent）。

## 1.2 大模型与传统专门工具的区别
- **早期方法：手写规则**。如判断垃圾邮件：出现某些词、链接很多、发件人可疑 → 提高风险分数。清晰、易解释，但真实世界太复杂，规则写不完，新词新写法新例外不断出现，规则很快漏掉情况。
- **后来思路：让模型从大量样例中自己找规律**。模型看过很多垃圾邮件和正常邮件后，学到哪些表达可疑、哪些正常。
- **再往后**：图片、语音、长文本、代码都能进模型，但很长一段时间是"一个任务配一个模型"：翻译有翻译模型，识别有识别模型，换任务就要重新准备数据、重新训练。
- **大模型的关键变化**：同一个模型可以处理很多任务，不再是专门工具，更像**通用助手**——把学过的方法**迁移**到新问题上。

### 学习类比
- 传统规则系统 = 只背固定题型的学生：题目换个问法就答不上来。
- 大模型 = 见过很多题、读过很多材料的学生：不只记住某道题，能把方法迁移到新问题。

## 1.3 大模型"大"在哪（三个特点）
1. **参数规模大**：参数 ≈ 模型内部保存规律的"旋钮"。参数越多，能表达的模式越复杂。
2. **训练数据多**：从大量文本、代码、图片、音频等数据中学习语言、知识和模式。
3. **适用任务广**：同一个模型可处理问答、总结、翻译、写作、代码、多模态理解。

> "大" ≠ 永远正确：不一定知道最新信息；回答流畅也不代表每句话有可靠依据。

## 1.4 模型 / 平台 / 应用 三层
- **模型层**：负责理解和生成。例：**千问**（语言）、**万相**（图像/视频生成）。
- **平台层**：负责把模型用起来——体验模型、调用模型、接入知识库和工具。例：**百炼**。
- **应用层（Agent 工具）**：直接面向具体任务——读文件、写报告、做数据分析、辅助开发。例：QoderWork。

> 分清三层：有的是模型，有的是平台，有的是面向具体工作的应用。后面看到新产品就不容易混。
