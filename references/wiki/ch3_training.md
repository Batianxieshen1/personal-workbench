# Ch3 大模型怎样学会当助手

三步训练：**预训练 → SFT → 偏好对齐**（先学说话 → 再学听话 → 最后学得体）。

## 3.1 预训练（Pretraining）
- 类比：让模型**大量阅读**——新闻、书籍、网页、论文、代码、问答记录。读得越广，越熟悉语言怎么组织、知识怎么表达、前后文有什么关系。
- 训练任务：反复练习"**根据前面的 token 预测下一个 token**"。数据足够多且丰富时，模型学到语言规律、常识、专业表达和代码模式。
- **数据质量直接影响表现**：

  | 数据情况 | 可能影响 |
  | --- | --- |
  | 数据少 | 知识有限，容易犯低级错误 |
  | 数据多但质量低 | 可能学到错误、重复、偏见或无用信息 |
  | 数据多且质量高 | 泛化能力和理解力通常更强 |

- 所以预训练数据要**清洗治理**：去重、去噪、过滤低质量内容、移除有害内容、处理个人信息、尽量覆盖不同语言和领域。
- 预训练之后：模型已经见过很多知识，但**还不一定会按你的要求回答**——更像续写文本，而不是判断你真正想要什么。

## 3.2 SFT（Supervised Fine-Tuning，监督微调）
- 解决的问题：从"会续写"变成"**会按要求回答**"。
- 做法：给模型看大量高质量的"**指令-回答**"样本：用户这样问，答案应该这样写；这个场景要简洁回答，那个场景要分步骤说明；要求表格就尽量按表格输出。
- 与预训练不同，SFT 更看重**示范质量**：样本要像真实问题、答案要可靠、格式要清楚；专业任务需要懂专业的人参与设计和审核。
- 公开研究佐证：**GPQA** 收集生物、物理、化学领域专家编写的研究生级问题；**PHYSICS** 整理大学物理和博士资格考试级别的问题。说明同一原则：专业能力不能只靠泛泛的问答样本堆出来，高质量题目、可靠答案、专家审核都很重要。
- 经过 SFT：让它总结就总结、翻译就翻译、按表格输出就尽量按表格输出。

## 3.3 偏好对齐（Preference Alignment）
- 解决的问题："**什么样的回答更合适**"。有些回答太啰嗦，有些看起来自信但依据不足，有些问题本来就不该直接回答。
- **RLHF**（基于人类反馈的强化学习）：让模型针对同一个问题生成多个回答 → 请人比较哪个更有用、更安全、更符合事实 → 模型根据反馈调整回答方式。
- **DPO**（直接偏好优化）：直接利用"回答 A 比回答 B 更好"这样的偏好数据优化模型，不单独训练"评分老师"。
- 目标不是单纯补知识，而是**让模型更会表达**：该回答时回答得有帮助，该拒绝时拒绝得稳妥，该说明依据时把依据说清楚。

> 一句话：大模型不是突然变成助手的——先预训练获得语言和知识，再 SFT 学会按指令回应，最后偏好对齐调整回答方式。
